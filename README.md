# Spine Abnormality Detection

Classify back pain as normal or abnormal from physical spine measurements.

## Approach

- Exploratory and statistical analysis of spine measurements
- Random Forest, Naive Bayes, KNN, SVM and Logistic Regression

## Results

Accuracy between about 0.68 and 0.86 in the saved notebook output.
